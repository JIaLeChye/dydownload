常规公开视频已支持免 Cookie 解析；仅在回退 PC Web 备用通道（部分特殊作品）时需要有效的 sid_guard 与 UIFID。

获取方法：
1. 浏览器登录 douyin.com，按 F12 打开开发者工具
2. 切换到 Application (应用) → Cookies → https://www.douyin.com
3. 复制 sid_guard 和 UIFID（无则取 UIFID_TEMP）的值，或直接从 Network 复制完整 Cookie
